The tool is a self-contained Python script that probes a WHM instance for CVE-2026-41940. It requires a single mandatory argument — `--target` — and walks through four stages to confirm whether authentication can be bypassed without valid credentials.

## Basic invocation

Pass the full WHM URL (scheme + host + port) to `--target` and the script does the rest:

```bash
python watchTowr-vs-cPanel-WHM-AuthBypass-to-RCE.py --target https://target:2087/
```

The URL must include:

- **Scheme** — `https` (WHM does not serve over plain HTTP by default)
- **Hostname or IP** — the address of the WHM server
- **Port** — `2087` is the default WHM port; change it if your instance uses a non-standard port

## CLI arguments

<ParamField path="--target" type="string" required>
  Full WHM URL to test, e.g. `https://target:2087`. Must include the scheme and port.
</ParamField>

<ParamField path="--hostname" type="string">
  Override the `Host:` header sent with every request. When omitted, the tool auto-discovers the canonical hostname by following the 307 redirect that cpsrvd issues from `/openid_connect/cpanelid`.
</ParamField>

<Note>
  When testing against a local VM or container, use the actual IP or hostname of the instance rather than `localhost`. WHM's cpsrvd may redirect `localhost` requests to the canonical hostname, which can confuse hostname auto-discovery.
</Note>

<Warning>
  Run this tool only against systems you own or have explicit written authorization to test. Unauthorized use against third-party infrastructure is illegal.
