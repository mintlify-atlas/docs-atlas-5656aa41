## Related vulnerability classes

CVE-2026-41940 combines three vulnerability classes that work together across the four-stage exploit chain.

**CRLF injection (CWE-93)** — The root cause. cpsrvd fails to sanitize carriage return and line feed characters (`\r\n`) in the `Authorization: Basic` header before writing them to the session file on disk. This allows an attacker to inject arbitrary key-value pairs — including `user=root`, `hasroot=1`, and `tfa_verified=1` — directly into a legitimate pre-authentication session.

**Session fixation (CWE-384)** — The amplification mechanism. After the CRLF injection writes forged fields into the raw session file, a request to `/scripts2/listaccts` triggers the `do_token_denied` gadget, which promotes the raw session into cpsrvd's authenticated session cache. This fixates the attacker's pre-auth session as a fully authenticated root session without requiring a valid password.

**Improper authentication (CWE-287)** — The net result. Because cpsrvd trusts the session cache values written by earlier stages, subsequent requests using the same session cookie are treated as authenticated root-level WHM access. The server never validated that the credentials used to mint the session were correct.
