This tool was built by [watchTowr Labs](https://labs.watchtowr.com/) researcher Sina Kheirkhah ([@SinSinology](https://x.com/SinSinology)) to detect whether a cPanel/WHM instance is vulnerable to CVE-2026-41940. The tool operates as a detection artifact generator: it attempts to reproduce the authentication bypass and reports whether the target is susceptible — without performing destructive actions.

## What is CVE-2026-41940?

CVE-2026-41940 is a critical authentication bypass in cPanel/WHM caused by a CRLF injection flaw in the `Authorization` header handling of `cpsrvd`, the WHM daemon. An unauthenticated attacker who can reach port 2087 can inject forged session fields — including `user=root` and `hasroot=1` — into the server's session file. Once the injected session is promoted to cache, the attacker holds a valid root-authenticated WHM session with no credentials required.

The exploit chain proceeds in four stages:

1. Obtain a pre-auth `whostmgrsession` cookie via a failed login
2. Inject CRLF payloads into the session file via a crafted `Authorization: Basic` header
3. Trigger a `do_token_denied` gadget to propagate the raw session into the server's cache
4. Confirm root WHM access via the `/json-api/version` endpoint
