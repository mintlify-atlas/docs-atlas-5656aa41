This tool, developed by [watchTowr Labs](https://labs.watchtowr.com/), provides a detection artifact generator for **CVE-2026-41940** — a critical authentication bypass vulnerability in cPanel/WHM. By exploiting a CRLF injection flaw, an unauthenticated attacker can forge session credentials and gain root-level WHM access without any valid credentials.

## How it works

The tool chains four discrete stages to verify whether a cPanel/WHM instance is susceptible to the authentication bypass:

<Steps>
  <Step title="Mint a pre-auth session">
    A failed login to `/login/?login_only=1` causes cpsrvd to issue a `whostmgrsession` cookie. The tool extracts the session base token from the raw response header.
  </Step>
  <Step title="CRLF injection via Basic auth">
    A crafted `Authorization: Basic` header containing CRLF sequences is sent alongside the session cookie. This injects forged authentication fields into the session file, including `user=root` and `hasroot=1`.
  </Step>
  <Step title="Propagate to session cache">
    A request to `/scripts2/listaccts` triggers the `do_token_denied` gadget, which promotes the raw injected session into the server's cache — making it authoritative.
  </Step>
  <Step title="Verify root access">
    The tool calls `/json-api/version` using the leaked `cp_security_token`. A `200 OK` response with a valid version payload confirms unauthenticated root-level WHM access was achieved.
  </Step>
</Steps>
